# 2026 정부혁신박람회 안내 사이트 확장 설계

날짜: 2026-08-01
대상: `government-innovation-expo-archive` (배포: hosungseo.github.io/government-innovation-expo-archive)

## 목표

수요조사 기간 참여기관 대상 정적 안내 페이지를 유지하면서 세 가지를 보강한다.

1. **역대 아카이브 완성** — 2018~2023 개최 내역(명칭·주제·기간·장소·개요)을 공식 출처(행안부 보도자료, korea.kr, 혁신24 등)로 확인해 카드 추가. 확인된 연도만 "공식 출처 확인"으로 게시하고 출처 링크·확인일 표기. 확인 불가 연도는 "정리 예정" 유지.
2. **기업 참여 안내 섹션 신설** — 참여 유형(전시·체험·기술 시연), 절차(수요조사 → 선정 → 전시 준비), 문의 경로. 공개 자료 기준, 미확정 항목은 "확정 시 공지" 표기. 네비게이션에 항목 추가.
3. **2026 개최 정보 갱신** — 공개 자료 조사 결과를 히어로·일정 섹션에 반영. 미확정 항목은 현행 유지 + "확정 시 공지". 이후 담당자 확정 정보로 덮어쓴다(혼합 방식).

## 비변경 사항

- 단일 페이지 구조, 디자인 토큰(tokens.css)·레이아웃·배포 방식(GitHub Pages)·URL 유지
- 아카이브는 기존 관례(inline HTML + data 속성, script.js 검색·필터) 그대로 확장
- 개인정보 수집·외부 스크립트 없음 유지

## 검증

- 확인 전 자료는 게시하지 않는다는 기존 원칙 준수 (모든 카드에 공식 출처 URL 필수)
- 로컬 서버로 렌더링·검색 필터 동작 확인 후 배포
